== Interpretation ==
VID overlap low (~48%) is a labeling artifact: inserted vectors receive run-dependent
VIDs (differ by insertion order/sharding), so base-vector VIDs match but inserted-copy
VIDs are renumbered. Distance is the correct invariant. 182/200 (91%) queries return
bit-identical sorted top-5 distances; the ~17 differing queries are single-neighbor ANN
approximation misses that go BOTH ways (baseline better on some, distributed better on
others, e.g. q0). => distributed search is equivalent to the single-node oracle;
head replication + posting sharing are consistent across nodes.
